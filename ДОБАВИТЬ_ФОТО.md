# Куда добавить фото

Сохрани фото в PNG и назови файл `profile.png`. Путь внутри репозитория:

```text
assets/profile.png
```

После загрузки файла картинка появится слева в `README.md`. В GitHub открой репозиторий `wextikit00`, выбери **Add file → Upload files**, загрузи `profile.png` в папку `assets` и нажми **Commit changes**.
